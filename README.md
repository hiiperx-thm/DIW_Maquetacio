# Pràctica Multimèdia - Disseny d'Interfícies Web

### Exercici 1: Transicions

- **Galeria d'imatges:** Les transicions de `scale`, `rotate` i `grayscale` es troben al fitxer `style.css` (línies 393-418). S'ha utilitzat un contenidor amb `overflow: hidden` per evitar que el zoom surti de l'àrea.
- **Transició a criteri:** Aplicada al botó de reserva (`.btn-submit`) al fitxer `style.css` (línies 534-540). Utilitza 3 propietats: `background-color`, `transform` i `box-shadow`.

### Exercici 2: Animació CSS

- **Text inicial:** L'animació del títol de la capçalera està definida al fitxer `style.css` sota el nom `@keyframes textAppears` (línies 121-146). Utilitza 4 frames i modifica l'opacitat, el desplaçament i el color.

### Exercici 3 i 4: Vídeo i Controls Personalitzats

- **Apartat de vídeo:** Es troba a `index.html` (línies 172-187).
- **Controls personalitzats:** S'han creat amb Google Fonts i una capa de fons fosc-transparent. L'estil es troba a `style.css` (línies 420-466) i la interactivitat a l'script d'`index.html` (línies 253-287).
- **Efecte Shadow:** Aplicat a les icones del vídeo en fer hover a `style.css` (línia 463).

### Exercici 5: JavaScript amb Scroll

- **Efecte Shrink Navbar:** El script que detecta l'scroll es troba al final de `index.html` (línies 257-270). La classe CSS que aplica el canvi de tamany i opacitat és `.header-shrink` a `style.css` (línies 43-48).
